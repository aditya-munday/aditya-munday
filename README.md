## <img src="https://media.giphy.com/media/W5N6TjFK5kzB6/giphy.gif" width="26"/> Flagship work

### 🧠 Directioner-OS — the AI-native Fedora
> *"The differentiator is not that the OS can talk. It is that the OS employs an engineer."*

A Fedora-derived OS with a resident, multi-agent **AI Engineer** that can plan,
implement, test, review, ship, monitor and roll back changes across the machine
— while preserving determinism, transparency and user sovereignty.

`Fedora bootc` · `Rust workspace` · `SELinux` · `polkit` · `QEMU smoke tests`

### 🛰️ Aria — native voice assistant
A desktop (not web) assistant that lives in the background, wakes on a word or a
global shortcut, and surfaces a floating orb — never stealing focus. Ships typed
`aria-core`/`aria-platform` crates and a versioned desktop ⇄ backend wire contract,
with multi-turn context, streaming and barge-in.

`Rust` · `TypeScript (Electron)` · `audio` · `wake-word`

### ⌨️ Directioner CLI — local-first AI coding agent
A bring-your-own-key terminal agent that inspects your repo, edits code, runs the
checks that matter, and reports what actually happened. Hardened against prompt
injection, filesystem and terminal abuse.

`TypeScript` · `BYOK` · `--doctor` · `hardened`

### ⚙️ Directioner Platform Backend
Shared identity, AI, data, task, entitlement and integration layer. Never executes
privileged ops itself — it requests them from the OS through an explicit allowlist.

`Node 24` · `Fastify 5` · `Zod` · `OpenAPI 3.1` · `Supabase` · `Vitest`
